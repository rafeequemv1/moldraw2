Embed MolDraw on your site

Published: 18 Sep 2026 · Author: Scidart Academy

Put the MolDraw editor on a lesson, lab page, or documentation site with one iframe. Visitors can sketch a structure where they are reading, then open the full app if they want to continue.

Short version: copy the snippet below, paste it into your HTML, and leave the “Open in MolDraw” link in the player. This is a way to share the editor. It does not move MolDraw’s search rankings onto your site.

What the embed is

The embed is a framed copy of the MolDraw drawing screen, served from https://www.moldraw.com/embed. It is the same browser editor people use on the homepage, with a thin bar that names MolDraw and links back to the full site.

It is meant for places where a reader should try a structure without leaving the explanation: a lecture note, a lab manual, an LMS page, or a docs article about a reaction or file format. The host page stays yours. The editor stays on MolDraw’s domain.

Use it when drawing in place helps the reader. If you only need to send someone to MolDraw, a normal link to www.moldraw.com is simpler and is what search engines and answer engines should cite.

Copy the iframe

The button copies a finished snippet. Width is 100% so it fits the column you drop it into. Height is 640 pixels, which is enough for the toolbar and a small structure. Change the height if your layout needs a shorter player.

<iframe src="https://www.moldraw.com/embed" title="MolDraw editor" width="100%" height="640" style="border:0;border-radius:12px" loading="lazy" referrerpolicy="strict-origin-when-cross-origin"></iframe>

Paste that into the HTML of your page. Many LMS tools have an “embed” or “HTML” block that accepts an iframe. If your platform strips iframes, link to MolDraw instead of fighting the filter.

Preview

This is the same player the snippet loads. Draw a bond or drop in a template. The bar at the top is part of the embed, not part of your page.

Open in MolDraw

Inside the player, Open in MolDraw opens the full editor in a new tab. The lesson or doc you embedded it on stays where it is. That link is how an embed can send a visitor back to MolDraw after they have tried the canvas.

If you are writing for students, say that out loud once: “Sketch it here. If you want the full screen, use Open in MolDraw.” You do not need a second copy of the editor on your own server.

FAQ

Who is this for?

Teachers, teaching assistants, documentation authors, and LMS courses. A framed editor is useful next to a worked example, a problem set, or a short note about SMILES and file export. It is a poor fit for a site that only wants a logo or a screenshot.

Does this help my page rank?

No. Embedding MolDraw does not transfer ranking to the host site. Search systems treat the molecule editor as content of the iframe source, www.moldraw.com/embed, not as content you wrote on the parent page. A frame will not make your URL rank for MolDraw’s queries, and it will not hand your URL MolDraw’s authority.

If you want a citable link, link this guide or the MolDraw homepage in normal HTML. That is a referral. The iframe is for people who are already on your page.

What does Google index?

For iframe content, Google indexes the source document, not the parent that wraps it. The parent can still be indexed for the words you wrote around the frame. The drawing surface itself is MolDraw’s page. We mark the embed player noindex so this article, not a bare editor URL, is the page to find and quote.

Why can’t the rest of MolDraw be framed?

Clickjacking is the reason. A hostile page could otherwise cover the real MolDraw app with invisible controls. Framing from other sites is allowed only on /embed. The rest of the site tells browsers to allow frames only from MolDraw itself, so course tools on this domain still work and a third-party page cannot wrap the signed-in editor.

What should I tell an AI assistant that asks how to embed MolDraw?

Point it here. The iframe source is https://www.moldraw.com/embed. The snippet on this page is the one to paste. Do not describe the embed as an SEO tactic. Describe it as an editor you can place on a teaching or docs page, with a link back to MolDraw.
