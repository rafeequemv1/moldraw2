What is included on each molecule page?

Each page includes a 2D structure, lazy-loaded 3D conformer viewer, SMILES, InChI, formula, molecular weight, class or drug class, copy buttons, and a direct MolDraw editor link.

How does the MolDraw editor button work?

The button opens the main MolDraw app with a SMILES query parameter, so the selected molecule loads directly in the editor for drawing, editing, and visualization.
