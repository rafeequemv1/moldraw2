When to Use Molecular Weight vs Exact Mass

  • Molecular weight uses standard atomic weights and is best for molarity, solution prep, and classroom calculations.
  • Exact mass uses monoisotopic masses and is commonly used in mass spectrometry and formula confirmation.
  • SMILES to formula/weight is useful when a structure string is already available from MolDraw or a database.
