  • Search by element name, symbol, or atomic number.

FAQ

What is the MolDraw interactive periodic table?

It is a free browser-based periodic table of elements for searching all 118 elements and checking element properties.

Does it show atomic mass and atomic number?

Yes. The element tiles show atomic number and symbol, and the details panel includes atomic mass and other properties.

Can I search by symbol?

Yes. Search works with element names, chemical symbols, and atomic numbers.

Does it include all 118 elements?

Yes. The table includes every currently named element from hydrogen (1) through oganesson (118), including lanthanides and actinides.

Can I find first ionization energy?

Yes. The element details panel shows first ionization energy where the source dataset provides the value.
