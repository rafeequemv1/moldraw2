File Format Explained

MOL and SDF files store atom and bond blocks, often with 2D or 3D coordinates. They are useful for editable structure exchange and compound data records.

SMILES converts that structure into a compact one-line text notation. It is useful for search, identifiers, scripts, and web tools.

When converting MOL or SDF to SMILES, check stereochemistry, charges, salts, and aromaticity. Some coordinate or property data from the source file will not be preserved in SMILES.
