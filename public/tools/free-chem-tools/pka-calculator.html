Henderson-Hasselbalch pKa Formula

  • pH: pH = pKa + log10(base / acid).
  • pKa: pKa = pH - log10(base / acid).
  • base/acid ratio: base / acid = 10^(pH - pKa).

This educational calculator assumes ideal buffer behavior. Activity, ionic strength, temperature, and buffer capacity can shift real measured pH.
