How Structure to SMILES Works

This page embeds the existing MolDraw 2D editor and listens for realtime editor messages. When Ketcher updates the molecule, the tool reads the generated SMILES and displays it in the output box.

  • Use it when you want to sketch a molecule and immediately copy a SMILES string.
  • Check stereochemistry, charges, aromaticity, and salts before using SMILES in databases or modeling workflows.
  • For the reverse workflow, use the SMILES to Structure tool.
